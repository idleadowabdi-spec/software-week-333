## 1.3 Difference Between Hot Reload and Hot Restart

**Hot Reload:** Hot Reload applies most code changes to a running Flutter application without restarting the entire application. It generally preserves the current application state. Developers use it to test changes to widgets, layouts, and user interface design quickly.

**Hot Restart:** Hot Restart restarts the application and resets its in-memory state. Developers use it when they need the application to start again from its initial state.

**Conclusion:** Hot Reload is useful for quick code changes, while Hot Restart is useful when a complete application restart is needed.

## 2.4 Security Reflection

Using the MySQL root account for direct application connections is poor security practice because root has extensive administrative privileges. If an application is compromised, an attacker could gain access to sensitive data, modify database structures, or delete important information.

The principle of least privilege means giving each user only the permissions needed to perform their tasks.

The following SQL commands create a dedicated application user:

```sql
CREATE USER 'school_app'@'localhost'
IDENTIFIED BY 'Replace_With_A_Strong_Password';

GRANT SELECT, INSERT, UPDATE
ON school.*
TO 'school_app'@'localhost';

SHOW GRANTS FOR 'school_app'@'localhost';
```

The `SELECT` privilege allows reading data, `INSERT` allows adding records, and `UPDATE` allows modifying existing records. These permissions are limited to the `school` database.

A strong, unique password should replace the placeholder password. The application should not use the root account for normal database operations.

# Section 3: Task 3 - Python Virtual Environment

## 3.1 Create the Project Directory

Commands used in Windows PowerShell:


These commands create the project directory and move into it.

## 3.2 Create and Activate the Virtual Environment

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

The first command creates an isolated virtual environment named `venv`. The second command activates it in Windows PowerShell.

When the environment is active, the terminal prompt displays `(venv)`.

## 3.3 Install and Verify the Requests Library

```powershell

python -m pip list
```

The first command installs the Requests library. The second command displays the installed Python packages so that the installation can be verified.

## 3.4 Export the Environment Configuration

```powershell
python -m pip freeze > requirements.txt
Get-Content requirements.txt
```

The `pip freeze` command exports the installed packages and their versions into `requirements.txt`. The `Get-Content` command displays the file contents.

**Expected Project Structure:**

```text

├── venv/

```

The virtual environment isolates project dependencies from other Python projects. The requirements file makes it easier to reinstall the same package versions later.
